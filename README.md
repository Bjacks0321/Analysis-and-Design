# Reflection

# What was the problem you were solving in the projects for this course?
In Project One, the primary objective was to design and analyze three distinct data structures—Vector, HashTable, and Tree—for storing and managing course information. This involved creating pseudocode and thoroughly examining each structure's runtime and memory complexities. 

In Project Two, the primary objective was to implement a command-line program in C++ that effectively utilized the Binary Search Tree (BST) data structure. The program aimed to read course data from a file, store it in a BST, and provide functionality for academic advisors to manage and retrieve information about Computer Science courses. The specific tasks included loading data into the data structure, printing an alphanumeric list of courses, printing course information based on user input, and ensuring adherence to industry-standard best practices in code design.
  
# How did you approach the problem? Consider why data structures are important to understand.
- I tackled the problem by creating a pseudocode for each data structure and focusing on the core operations required. I then analyzed the runtime and memory complexities, considering factors such as insertion, deletion, and retrieval operations. Having a good understanding of data structures was crucial in selecting the most suitable structure for the application's specific needs.

- I designed this project's binary search tree (BST) data structure to handle course data efficiently. I implemented various methods for loading data, sorting courses, and searching for specific information. This project highlights the importance of using data structures to solve real-world problems and emphasizes the significance of algorithmic efficiency.

# How did you overcome any roadblocks you encountered while going through the activities or project?
- In RunTime Analysis, the complexity of this challenge lies in translating theoretical understanding into a concrete analysis that accurately reflects the runtime behavior of the algorithms. Verifying the pseudocode's alignment with runtime analysis required meticulous attention to detail and a deep comprehension of the underlying principles.
To overcome this roadblock, I employed an iterative approach. I revisited the pseudocode step by step, validating each operation against the theoretical runtime analysis. Discussing the pseudocode's nuances with others clarified ambiguities and provided valuable insights into optimizing the analysis.
- For Project Two, my challenges included managing input/output operations, ensuring correct data loading, and implementing the sorting algorithm. Breaking down the problem into smaller tasks, testing incrementally, and debugging were crucial in overcoming these challenges.
  
# How has your work on this project expanded your approach to designing software and developing programs?
Reflecting on these projects, I recognize how they have expanded my approach to software design. Selecting the proper data structure for specific tasks has become a central consideration. The trade-offs between structures and their impact on runtime and memory have significantly influenced my design process. This course has heightened my awareness of algorithmic efficiency in practical applications.

# How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?
Moreover, these projects have shaped how I write programs—prioritizing maintainability, readability, and adaptability. Clear commenting, modular design, and adherence to coding standards are now integral aspects of my programming practices. The iterative nature of problem-solving has underscored the need for code that is not only functional but also easy to understand and maintain.
